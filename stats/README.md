# ตั้งค่าเก็บสถิติลง Google Sheet
1. เปิดชีต "เก็บข้อมูล" → ส่วนขยาย → Apps Script → วางโค้ดจาก stats/Code.gs แทนของเดิม → บันทึก
2. ทำให้ใช้งาน → การทำให้ใช้งานใหม่ → ประเภท "เว็บแอป" → เรียกใช้ในฐานะ: ฉัน · ผู้มีสิทธิ์เข้าถึง: ทุกคน → ทำให้ใช้งาน → อนุญาตสิทธิ์
3. คัดลอก URL ที่ลงท้ายด้วย /exec ไปวางที่ ENDPOINT ใน lib/stats.js
