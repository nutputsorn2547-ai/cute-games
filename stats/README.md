# ตั้งค่าเก็บสถิติลง Google Sheet (แบบ 1 ครั้งที่เข้าเล่น = 1 แถว)
1. เปิดชีต "เก็บข้อมูล" → ส่วนขยาย → Apps Script → วางโค้ดจาก stats/Code.gs แทนของเดิมทั้งหมด → แก้ `KEY` เป็นรหัสเดิมของคุณ → บันทึก
2. ทำให้ใช้งาน → **จัดการการทำให้ใช้งาน** → ไอคอนดินสอ → เวอร์ชัน "เวอร์ชันใหม่" → ทำให้ใช้งาน (ใช้ URL /exec เดิม ไม่ต้องแก้ ENDPOINT)
3. (ครั้งเดียว) เลือกฟังก์ชัน `migrate` ที่แถบด้านบน → เรียกใช้ → ย้ายข้อมูลแท็บ "log" เก่ามาเป็นแท็บ "sessions" และ "rtt" เมื่อเช็กในหน้า stats ว่าข้อมูลครบแล้ว ลบแท็บ "log" ทิ้งได้
## แท็บในชีต
- `sessions` : 1 แถว = 1 ครั้งที่เข้าเล่น อัปเดตทับแถวเดิมตอนเข้า / ระหว่างเล่นทุก 3 นาที / ตอนออก
- `rtt` : ความหน่วงของมือถือที่เชื่อม เพิ่มแถวเฉพาะตอนมีมือถือเชื่อมอยู่ ทุก 3 นาที
