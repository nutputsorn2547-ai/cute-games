# ตั้งค่าเก็บสถิติลง Google Sheet
1. เปิดชีต "เก็บข้อมูล" → ส่วนขยาย → Apps Script → วางโค้ดจาก stats/Code.gs แทนของเดิม → ใส่รหัสเดิมที่ `KEY` → บันทึก
2. ทำให้ใช้งาน → จัดการการทำให้ใช้งาน → ไอคอนดินสอ → เวอร์ชันใหม่ → ทำให้ใช้งาน (ใช้ URL /exec เดิม ไม่ต้องแก้ ENDPOINT)
3. ครั้งแรกที่ทำให้ใช้งาน ให้กด "อนุญาตสิทธิ์" เพิ่ม (ปุ่มบังคับรีเฟรชใช้ PropertiesService)
## ปุ่มบังคับรีเฟรช
หน้า /stats/ มีปุ่ม "บังคับรีเฟรชทุกคน" → Apps Script เก็บเวลาที่กดไว้ → หน้าเกมออฟฟิศจำลองถามทุก 90 วินาที ถ้าเวลาเปลี่ยนจะเซฟเกมแล้วรีเฟรชเอง

## กล่องข้อความจากผู้เล่น (คอลเซ็นเตอร์)
- หน้าแรก มีปุ่ม "💌 ส่งข้อความถึงผู้สร้าง" → เลือกเกม (ติ๊กหลายอัน/ทั้งหมด) ให้ดาวแยกแต่ละเกม พิมพ์ข้อความ ต้องใส่ชื่อผู้ส่ง (จำไว้ในเครื่อง ผูกกับรหัสเครื่อง)
- ข้อความเก็บในชีต `inbox` (Apps Script สร้างให้เองครั้งแรก) · กันสแปมเครื่องละ 6 ข้อความ/ชั่วโมง
- หน้า /stats/ มีแผง "📨 กล่องข้อความจากผู้เล่น" อ่านและตอบกลับได้ ผู้เล่นเห็นคำตอบในแท็บ "ข้อความของฉัน" (เช็กทุก 90 วินาที)
- ต้องวาง Code.gs ล่าสุดแล้ว Deploy เป็นเวอร์ชันใหม่ (ครั้งแรกอาจต้องกด "อนุญาตสิทธิ์" เพิ่ม เพราะสคริปต์สร้างชีตใหม่)

## แชทในเกมออฟฟิศ (แยกจากกล่องข้อเสนอแนะ)
เก็บในชีต `gamechat` แยกต่างหาก (สร้างอัตโนมัติ) แสดงเป็นกล่อง "💬 แชทในเกมออฟฟิศ" ใต้กล่องข้อความจากผู้เล่น — ต้อง Deploy Code.gs เวอร์ชันใหม่
