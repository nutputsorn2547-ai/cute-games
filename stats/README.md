# ตั้งค่าเก็บสถิติลง Google Sheet
1. เปิดชีต "เก็บข้อมูล" → ส่วนขยาย → Apps Script → วางโค้ดจาก stats/Code.gs แทนของเดิม → ใส่รหัสเดิมที่ `KEY` → บันทึก
2. ทำให้ใช้งาน → จัดการการทำให้ใช้งาน → ไอคอนดินสอ → เวอร์ชันใหม่ → ทำให้ใช้งาน (ใช้ URL /exec เดิม ไม่ต้องแก้ ENDPOINT)
3. ครั้งแรกที่ทำให้ใช้งาน ให้กด "อนุญาตสิทธิ์" เพิ่ม (ปุ่มบังคับรีเฟรชใช้ PropertiesService)
## ปุ่มบังคับรีเฟรช
หน้า /stats/ มีปุ่ม "บังคับรีเฟรชทุกคน" → Apps Script เก็บเวลาที่กดไว้ → หน้าเกมออฟฟิศจำลองถามทุก 90 วินาที ถ้าเวลาเปลี่ยนจะเซฟเกมแล้วรีเฟรชเอง
