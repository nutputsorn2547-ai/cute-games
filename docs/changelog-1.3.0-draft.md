- **ช่วงคุ้มครองมือใหม่**: 31 วันแรกของเซฟ และ 7 วันหลังย้ายบริษัท หัวหน้าสอนงานแทนการตำหนิ ไม่หักความเครียด/คะแนน (สถิติยังบันทึก)

- **สมุดความสำเร็จบนโต๊ะ**: แท็บแสตมป์ (16 ดวง ย้อนหลังจากข้อมูลจริง) และแท็บเกียรติบัตร

- **รีวิวผลงานรายเดือน** ทางอีเมลฝ่ายบุคคล (ไม่กระทบเงินเดือน/ตำแหน่ง ลาป่วยไม่ทำให้คะแนนตก)
- **กลับบ้าน**: จอดำ → สรุปภาพรวมของวัน (ย้อนดูได้ 31 วัน) → นอนหลับข้ามไปเช้า

- เอาห้องพักหน้าตกแต่ง (เฟอร์นิเจอร์/งานบ้าน/สัตว์เลี้ยง) ออกจากเบต้า ข้อมูลเก่าในเซฟยังอยู่
